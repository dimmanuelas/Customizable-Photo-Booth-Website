# 📸 Customizable Photo Booth

> Aplikasi web interaktif berbasis web untuk mengambil foto, memilih *frame* atau filter kustom, dan mengunduh hasilnya secara instan. Cocok untuk acara, pesta, atau proyek portofolio kreatif!

[![Status: Active](https://img.shields.io/badge/Status-Active-success.svg)](https://dimmaproject.rf.gd/webapp/Customizable-Photo-Booth/)

---

## ✨ Fitur Utama

- **📷 Tangkap Langsung (Live Capture):** Integrasi langsung dengan kamera perangkat (webcam/kamera depan/belakang) menggunakan API Browser.
- **🎨 Kustomisasi Frame & Layout:** Pilihan tata letak foto (strip, grid, dll.) dan bingkai (*frame*) yang dapat diubah sesuai tema acara.
- **✨ Filter & Efek:** Penambahan filter warna (grayscale, sepia, retro, dll.) secara *real-time* sebelum foto disimpan.
- **💾 Unduh & Bagikan:** Pengguna dapat langsung mengunduh hasil gabungan foto dalam format PNG/JPEG berkualitas tinggi.
- **📱 Responsive Design:** Berjalan dengan mulus baik di perangkat desktop maupun *mobile*.

## 🚀 Memulai (Installation & Setup)

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek secara lokal di komputer Anda.

### Prasyarat
Pastikan Anda telah menginstal perangkat lunak berikut di komputer Anda:
- [Node.js](https://nodejs.org/) (Versi 16.x atau yang lebih baru)
- Git

### Langkah Instalasi

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/username/Customizable-Photo-Booth-Website.git
   ```

2. **Masuk ke direktori proyek:**
   ```bash
   cd Customizable-Photo-Booth
   ```

3. **Instal dependensi:**
   ```bash
   npm install
   ```

4. **Jalankan server pengembangan (*development server*):**
   ```bash
   npm run dev
   ```

5. Buka peramban (*browser*) dan akses `http://localhost:3000` (atau *port* sesuai terminal Anda).
